Bocetos de la web del ciudadano de EcoRuta San Juan, para aprobar antes de programarla. Los datos son de ejemplo: ruta Centro–UNERG, parada Plaza Bolívar.

Teléfono: las tres alturas del panel

El panel abre en la altura baja. Se sube arrastrando el asa o tocando «Ver las 3 llegadas», que hace lo mismo para quien no puede arrastrar.

Teléfono: avisos y estados

Lo que pasa antes de tener parada y cuando algo no anda. Sin ubicación no hay elección manual: es una decisión del producto.
